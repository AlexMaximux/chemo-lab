# Chemistry Lab Simulator Implementation Plan

> **For agentic workers:** Implement task-by-task. Steps use checkbox syntax. The builder is Antigravity (`agy`); the manager (Claude) reviews each task's gate before the next starts.

**Goal:** Browser chemistry lab with a real, tested chemistry engine, a professional bench UI, and a lab notebook.

**Architecture:** `src/engine` is a pure TypeScript module (no DOM) holding species data, reaction table, thermodynamics, solution/pH, kinetics and a time-stepped simulator. `src/ui` renders a Canvas 2D bench and DOM panels on top of the engine. `src/notebook` logs actions and graphs.

**Tech Stack:** TypeScript, Vite, Vitest, Canvas 2D, plain CSS (dark instrument-panel theme).

**Spec:** `docs/superpowers/specs/2026-10-22-chem-lab-design.md`

## Global Constraints
- Engine has zero DOM imports.
- Run in modern Chrome and Safari at 1280x720 and up.
- 60+ species, 40+ reactions, at least 8 hazardous reactions.
- Every species/reaction data entry has a `source` field (NIST WebBook, PubChem or CRC).
- Reaction dH must match Hess's law from species formation enthalpies within 1 kJ/mol.
- Every reaction is atom- and charge-balanced (automatic test).
- Mass conserved in every simulated mix.
- Unmatched mixes return "no reaction", never throw.
- Notebook persists in localStorage; export JSON and CSV.
- `npm test` and `npm run build` must pass at the end of every task.

## Review Focus
- Mixing more of a reagent than the vessel holds: overflow shown, no negative volumes.
- Zero or negative amounts, pouring from an empty container: ignored with a message.
- Heating an empty vessel or a closed vessel with gas: pressure rises, vessel can burst with warning.
- Mixing three or more chemicals where several reactions compete: deterministic order, mass still conserved.
- Reloading the page mid-experiment: notebook restores, bench resets cleanly.

### Task 4: Simulator (kinetics, limiting reagent, time stepping)
**Files:** Create `src/engine/simulator.ts`, `tests/engine/simulator.test.ts`.
**Interfaces:** Consumes `Mixture`, `REACTIONS`. Produces `class Simulator { constructor(m: Mixture, opts?: { vesselL?: number; closed?: boolean }); step(dtSeconds: number): StepResult; ignite(): void; heat(joules: number): void; events: LabEvent[] }` where `StepResult = { reactionsFired: string[]; heatJ: number; tempK: number; pressureKPa: number; hazards: string[] }`.
- [ ] Failing tests: 2 mol H2 + 1 mol O2 without ignition stays unreacted over 60 s; with `ignite()` converts fully to 2 mol H2O, releasing about 571.6 kJ (+-5); 3 mol H2 + 1 mol O2 ignites, leaving 1 mol H2 and 2 mol H2O (limiting reagent); atoms conserved after every step (element totals equal); NaOH + HCl neutralization raises temperature about 57 kJ/mol released; mixing unrelated species (NaCl + N2) yields empty `reactionsFired`; closed vessel with heated gas exceeds burst pressure and emits a `burst` hazard event.
- [ ] Implement Arrhenius rate with sub-stepping, deterministic reaction order, full-conversion or equilibrium per `reversible`. Run tests, expect PASS. Commit.
